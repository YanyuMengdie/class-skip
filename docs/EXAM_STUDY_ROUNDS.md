# 备考工作台：按讲义范围进行短轮输出练习

备考入口采用「选考试与讲义 → 提取 KC → 提取有原文页码的逻辑原子 → 按内容关系组织主题复习块 → 短轮完整作答 → 反馈回到对应原子」。目标是让学生练习完整输出，并知道下一步该补什么。单次成功不表示整份讲义已掌握，也不预测考试成绩。

## 页面与交互

- 顶部恢复两步提取：当前讲义 KC、逻辑原子与原文页码。已有清单直接使用；重新提取只替换当前讲义的结构，其它讲义及作答、旧 BKT 历史保留。实际 PDF 文字带物理页码标记进入提取，长文分批时保留后面的页。
- 左侧：考试、讲义、主题。AI 在既有 KC 上参考讲义章节线索、概念含义和联系分组，通常每组 2–4 个 KC，不硬凑；每个 KC 恰好属于一个主题，保留全部原子，不重新提取或改写知识点。主题来源是成员 KC 直接证据页的精确并集，不补中间空页；每个原子仍只能使用自己的出处。未知页码、空原子与未映射页面仍可在知识清单核对，不能冒充已经复习。分组按用户、考试、讲义、语言与内容版本缓存；失败可以重试，不破坏旧清单和作答。
- 知识清单：展示每个 KC、全部原子、原文页、旧覆盖记录及新的逐原子作答证据。访问清单（包括可见的 KC 名称）及展开要点说明会记录相关帮助。没有可核对内容时允许空原子，不强制凑 3 条。
- 中央：默认进入主题复习，完整知识清单仍可随时切换查看；提取与重新分组工具放在知识清单页。次数和计时收进本轮设置，新建轮次的 4 次预算最多选择 3 个已有原子，6 / 8 次预算最多选择 4 个（固定目标的旧轮复查保留原目标），先在组内各 KC 选一项，再轮流补选，每个 KC 内按未查、欠缺、辅助、复查等已有证据排序。一般安排 3 道主问题，4 次预算至多 3 道，6 / 8 次至多 4 道；保留可选修补空间，小范围不硬凑题。开始前只展示实际题数和覆盖要点数量，不展开会泄露结论的目标清单。答题页展示已审核的主题标题、题干及本地固定的中性形式说明；私有评分要求和预期答案在提交后才出现。可选择不限时、每题 3 分钟或 5 分钟；到时只提醒，不自动提交，暂停和离开复习块时停止累计。
- 下方帮助区：一点提示、直接讲解、回到原文。帮助可以随时用，使用条件会保留。需要补练时可在剩余预算内换题，追问同样占用一次回答。
- 右侧：原文页及引文定位。返回题目保留草稿；可继续翻阅 PDF。窄屏使用覆盖式预览和可收起的复习块栏。
- 结束页：逐目标展示在当前题目条件下未借助额外帮助完成、帮助后完成、还需补练、尚未检查、待核对。给出具体原答、题干条件、反馈和下一步。结束不要求把所有目标都变成成功。
- 单独保留整场材料对话、考试及资料管理、旧对话回看。BKT 代码与历史保留，主流程不使用掌握概率或预测分来选题、判定和决定结束。旧原子覆盖不转换成新的独立作答证据。
- 每项标准对应固定原子，按其自身结果与帮助条件跨轮汇总，整题答对不会点亮未考原子。一轮结束后可继续检查其它要点，或固定这批要点换题复查。未查、遗漏、依赖帮助、待复查用于安排后续。

视觉采用与阅读空间相近的暖白、浅灰绿和深绿，页码范围始终可见，正文保持适合阅读的宽度。动效只用于轻微出现、按钮和状态变化，并遵循减少动态设置；不使用庆祝式「通关」暗示掌握。

## 六个痛点如何处理

| 痛点 | 实际设计与约束 |
| --- | --- |
| 被课外知识考住，却以为自己没学会 | 客户端只向模型传所选材料/页码；目标和每项评分标准必须带该范围中真实存在的摘录。缺页、越界、无法匹配的引用会拒收。不会回退到整份讲义或其它材料来填补缺失。 |
| 永远考不完 | 用户先选回答上限，包含追问和重测。到上限即结束；可以主动结束或暂停。反馈服务重试不重复扣次数。报告保留尚未验证项。 |
| 一次错误就被贴专业诊断标签 | 不诊断学生。先展示原题要求、原答对应片段、哪些还没说到；下一步是提示、讲解、澄清或新题检查。学生能标记题目/评价有问题，并对照原要求重评。未接受的争议保持待核对。 |
| 一道题被包装成「86% 掌握」 | 不显示掌握百分比、PASS 或预测分。报告限定为本轮任务表现，展示原答及作答条件；历史用于追踪与间隔复查，不补成当前轮没测过的成功项。 |
| 耗时过长，只会打开一次 | 按小块进入，4 / 6 / 8 次是上限而非必须完成。逐次自动保存草稿、帮助与反馈；刷新、暂停、切块可续接。存储失败明确提示并支持导出，切块仍保留当前页面内存中的记录。 |
| 对话里会了，考试仍写不完整 | 每道题都要求先提交一份完整答案；回答要求和评分依据在答题前固定，不临时加标准。可选每题 3 / 5 分钟软计时，保留实际耗时与是否超出自选时限；另可明确选择 2–3 个块组合输出，或隔开一段时间用新题复查。它训练讲义范围内的输出，不把生成要求冒充老师的评分标准或考题预测。 |

## 证据与帮助

1. 每次回答保存原题、私有评分要求、原答、时间、题干线索程度、认知任务、知识连接、题面新旧及使用过的帮助。提交时深拷贝题目和条件快照，之后不改写原答。
2. 评价必须对应固定标准；评价中的学生引文必须存在于原答。无效题、未完成评价、无法确定及未解决的争议均不算独立成功。
   生成题目时，模型从客户端按选定页整理的编号摘录中选择引用。实际页码和原文由客户端恢复，避免模型改写或翻译摘录后无法定位。未知编号直接拒绝，既有记录的原文引用继续核验。
3. 原文实际翻页、提示、讲解、反馈、历史答案曝光按材料和页面保存。准备阶段还没创建轮次、切到整场聊天、切块后返回或刷新，都不能清除这些条件。
4. 跨材料旧对话没有可靠页码时采用明确的「该材料全部页面」曝光标记，不伪造页号。保守记录帮助，避免刚看完答案又被认作独立完成。
5. 24 小时仅为安排间隔复查的产品规则，不是学习保持性的科学阈值。展示实际间隔及是否为新题；一次间隔成功仍只是这一次的表现。
6. 新记录按用户和考试隔离保存在当前设备。页面内容指纹参与范围身份，PDF 发生改变后不继承旧内容的成功结论。不会自动删掉较早轮次以腾出存储空间。

## 答前提示与作答条件

- 新题不再把评分要求复制为答前提示。模型只返回回忆／解释／比较／应用的形式枚举，页面使用固定中性文案。准备页也不提前暴露逻辑原子中的结论。
- 每轮生成后增加一次整批 AI 核对，补题也要核对：同时检查实际可见主题标题、题干、形式说明和私有评分标准，拒绝提前泄露答案或因果链、隐藏不公平要求、材料不支持的题。核对后才冻结题目及条件；题干、标题、标准或来源发生变化会使核对标记失效。这会增加准备时间，并非保证 AI 永不误判。
- 「题干点名概念」与「使用额外帮助」分开记录。点名概念时未求助答对，可以保留为该条件下完成；不会因此补成低提示成功。未核对的旧题保留原答、反馈和草稿，提示条件记为待核对，不贡献新的成功或缺口判断；未答完的旧题提示准备新一轮。
- 报告和知识清单可展开查看四种线索程度下的实际记录，以及每次的认知任务、单点或连接、新旧表述、帮助条件。复合题按各原子自己的标准与帮助汇总，不能把一个原子的成功算给另一个。没有百分比、统一 PASS 或必须刷满的五维格子。
- 答后可选「少些提示再试」。它保留上一题原子、评分细则、来源、情境与推理要求，只减少题面线索。只有核对确认线索降低、任务和连接保持不变才接受；无法做到时保留当前反馈并允许换题或结束。本轮预算不增加，刚看过的答案、讲解和反馈继续计为帮助，不能伪装成独立回忆。

## 案例应用与题目变化

- 新轮以实际应用为主要部分：允许案例分析、比较解释、预测变化和解读结果；基础回顾用于必要起步，不以连续背定义代替应用。通常仍为三道主问题，但减少预选原子数量，为一题连接两三个确有联系的原子留出推理空间。公平轮选 KC 和逐原子回写保留；不会为了综合而发明讲义未建立的联系。
- 假设人物、情境、观测数据或实验条件可以新编，须自足、合理并标注假设。判分所需的知识、机制和关系仍必须由该原子的精确原文页支持；虚构数据不能冒充讲义的实验结果。题干要保留必要条件，但不代学生选出概念、给出因果链或答案。没有教过的方法不能作为隐藏的必答要求。
- 独立答前审核按真实任务标记基础、案例、比较、预测、结果解读，并逐原子识别哪些目标确实参与案例推理。给故事加一个人名、重复定义或在题干写出结果再要求复述，不能算案例应用。
- 审核材料可支持案例时，优先安排较少线索的应用或比较案例。题型变化、少出基础直问题是生成偏好，不再因为两道都是案例或基础题数量就拒绝整轮。缺少合适案例时，只允许一次针对实际审核结果的修补和独立复审；原目标、来源、题数和覆盖要求固定，不重新抽取原子，不无限重试。若已有通过全部内容检查的真实案例但题干仍较明确，保留这批有效题并明确提示，按实际线索条件记录，不能伪装成低线索完成。若始终只有基础题则明确说明案例修补失败；不得把生成失败说成材料不支持。审核一开始确认材料确实不足时仍保留具体原因，不把基础练习计为案例完成。准备按钮分别显示生成、核对和修补阶段。
- 新题使用中性题目标题，独立作答时外围主题名称也暂收起；主动查看名称或原文仍可进行并记录帮助。提交前只显示中性的任务类别和假设情境标记，不显示判分标准、知识提示或材料限制的具体内容；具体限制在答后才展示。
- 答后分别展示基础回顾、案例应用、较少线索案例的实际作答记录。复合题中只负责背定义的原子不能借用另一原子的案例成绩；帮助、遗漏、争议和无效记录分别保留。旧题没有新的案例审核时，保留原记录但不自动升级为案例证据。这些记录不表示考试匹配或整份讲义掌握，不要求逐格刷满。

## 简短回答与完整反馈

- 出题时只把该题真正必要的意思固定为评分要求。接受语义等价的白话、简短表达和有效的替代推理；不会因为没照抄术语或句子长度就判为不完整。定义题、机制题、比较题仍按各自实际要求检查，必要差别和因果方向不能省略。材料写过某细节，不表示每一道题都必须问到它。
- 新反馈按「已经说对的 → 本题还需要补的 → 一份简短完整的参考回答」组织。必要补充是最小的具体修正，不把“多写一点”当作普遍要求；不确定的表述保持待核对。
- 参考回答依据出题前固定的标准，连成自然的短答，并附原文来源。它必须覆盖且只引用本题标准，不能反过来增加评分点，也不冒充老师标准答案。讲义支持的可选延伸独立折叠，不影响该题结果或自动触发补练。
- 全部必需要点已回应时明确告知，并优先提供继续下一题。少提示重试仍是可选练习。最后一次回答即使触及次数上限，完整参考反馈仍在结束页直接展示。
- 旧答案与反馈保留。当前轮次的旧反馈可手动选择「按新方式整理反馈」，使用原题与原答重新评价，不新增提交次数、不修改原题标准；若旧标准多考了题干未要求的内容，则标为题目需要核对，不擅自改标准后判学生通过。

## 适用边界

当前以 PDF 可提取文字为出题依据。完全没有可读取文字的块不会强行出题；部分空白文字页会提示图像内容未被纳入。引文存在性和页码校验能够拦截引用错误，但不能在逻辑上保证模型对每条材料的解释、重要性判断或评价必然正确，因此保留原文与争议核对。

本轮目标来自已提取清单中选出的有限原子，不代表穷尽每一页的全部知识。提取清单本身仍可能有遗漏或解释错误，可以对照原文和未映射页核查。没有教师样题和评分细则时，不宣称题型匹配、考试覆盖或预计得分。软计时用于练习完整输出；允许暂停和借助提示，记录不冒充正式限时考试成绩。

## 验证

定向测试覆盖页码边界、缺页拒绝、资料版本变化、题目/标准/引文一致性、原答摘录、固定预算、服务重试、争议、无效评价、帮助与历史曝光、跨块和跨刷新保存、存储失败和中英界面。另通过生产构建及浏览器检查实际资料入口、任务界面、暂停恢复、原文返回与反馈流程。测试使用的合成材料与模拟 AI 与真实复习记录隔离。

全仓类型检查仍可能报告本轮开始前已有的阅读器、旧问答或服务文件问题；新模块应无新增类型错误。具体通过数量和浏览器结果以本次交付说明为准。
